# QA y DevOps

## Descripción del proyecto
Este repositorio se utiliza para organizar y documentar las actividades del proyecto académico de QA y DevOps, facilitando el control de versiones y el trabajo colaborativo.

## Objetivo
Mantener organizados los archivos del proyecto, documentar los cambios y aplicar buenas prácticas de gestión de versiones.

## Flujo de trabajo GitFlow
- main: contiene la versión estable del proyecto.
- develop: integra los cambios antes de incorporarlos a la versión principal.
- feature/registro-requerimientos: permite desarrollar y documentar funcionalidades específicas.

## Control de calidad
Los cambios deben revisarse antes de integrarse en la rama principal. La documentación debe mantenerse actualizada y los riesgos del proyecto deben identificarse y registrarse.

## Organización del repositorio
Los documentos, evidencias y demás entregables se incorporarán de acuerdo con las indicaciones del enunciado de la tarea.

## Integrantes
Proyecto académico grupal de QA y DevOps.
